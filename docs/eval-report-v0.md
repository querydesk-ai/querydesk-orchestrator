## Decisions taken (2026-10-10)

The proposals above were reviewed rather than copied verbatim:

- **`confidence_mid` = 0.49, not 0.56.** The "keep 90%" rule dropped exactly the two error-code
  questions (PWD-1407 at 0.497, CRM-5503 at 0.510). BM25 cites the right article for both (hit@1),
  but dense similarity rates exact codes low. 0.49 keeps all 20 informational questions; the
  0.49–0.56 band answers with a disclaimer. The one out-of-scope query in that band ("when is salary
  credited", 0.545) gets a disclaimer + SR offer, not a confident answer.
- **`confidence_high` = 0.56** as proposed.
- **`router_min_score` = 0.43** as proposed. Fragile: in-scope minimum 0.439, out-of-scope 0.430.
  Re-check when the eval set grows.
- **LLM tie-break disabled** (`router_tie_break_enabled=False`, `router_tie_margin=0.00`).
  Similarity alone picked 49/50 categories; the tie-break alone 44/50, because it answers `none`
  for informational questions (the prompt frames categories as requests). It costs ~1.4 s p50.

## Open risks

- **Embedding latency.** Dense embedding (`qwen3-embedding-8b`) is 1.6–2.2 s per query (BM25:
  ~2 ms). With answer generation (~1.2 s) the answer path cannot meet the PRD's p95 < 3 s.
  Needs a decision before Day 8.
- **Action detection.** 83% of action requests clear `confidence_high`, so the decision layer's
  rule 2 must not answer on score alone — Day 4 needs an explicit "is this an action?" signal.
